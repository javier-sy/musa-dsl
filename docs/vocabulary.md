# Vocabulary

Every name the subsystem documents teach, by subsystem. It answers *what is
there*, which is the question you cannot look up -- for what each one does,
follow the document, or the API reference at
[rubydoc](https://www.rubydoc.info/gems/musa-dsl).

Generated by `tools/vocabulary.rb` from the public API and the documents
themselves; the suite fails if it is out of date. A name missing here is
missing from the documents, and that is where to add it.
